## Observations

- Current page: dark, blue-accented, monospace-forward, technically credible, content-rich.
- Current strengths: clear install CTA, concrete code examples, platform coverage, API table, FAQ, GitHub destination.
- Current weaknesses: long dark slab rhythm, weak section differentiation, emoji-only feature iconography, low visual warmth, limited mobile-first hierarchy, and no strong signature visual beyond the grid/code panels.
- Product facts retained: one HTTP dispatch API, seven platforms, five install methods, queue backends, adapter contract, n8n integration, MIT/self-host positioning.

## Synthesized direction

"Open Infrastructure × Signal Garden × Rainbow Utility"

- Pure white canvas with black typography and saturated purple as the anchor.
- Violet-to-pink-to-cyan signal gradients used as controlled emphasis, not background noise.
- Glassy white surfaces, colored left stripes, dot-grid fields, radial orbs, and soft shadows create depth without hiding technical content.
- Code remains the proof object; it is presented as a terminal window and architecture artifact, not a fake product demo.
- The comparison section uses “It’s not hosted convenience, it’s owned distribution” as a positioning contrast.
- Testimonials are intentionally omitted because the current product has no verified customer proof.

## Explicitly rejected

- Copying VIAINTI, Beautiful UI, v0, MotionSites, or any repository layout one-to-one.
- Fabricated testimonials or customer metrics.
- Dark-only styling, excessive glass blur, decorative motion without hierarchy, and fake product screenshots.
